DCRC compatibility profile: Sonic Adventure USA V1.005.

This profile contains only executable hashes, function entry/end addresses and discovery origins, overlay bounds, and texture identifiers/names/dimensions. It contains no instructions, IR, binary payloads, generated game source, graphics, audio or executable. The own emitter must read a supported copy supplied locally by the user.

Address metadata provenance: validated separate Dream-Recomp discovery; source revision 51a148c7bf9191fa8593e707c4996cf887076b33. Discovery software is not included or linked. All 59 original metadata hashes are recorded in profile.json; the catalog projection preserves only entry/end/origin. Independently matched to the existing verified local generation inputs.

The expanded profile records five Chao modules, the alert window and thirteen upgrade scenes. The emitter reads the user's boot and PRS bytes to generate those bodies locally.
