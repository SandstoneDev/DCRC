# Contributing

Use the shared converter core for GUI/CLI behavior. Keep the current profile
reproducible and a second game's claims separate from research. Changes include
the relevant synthetic tests and a clear statement of what was actually run.

Do not submit disc/extracted files, generated game source, objects, ports,
patches of translated code, game/BIOS captures, private SDK material, console
identifiers, credentials, private paths or unlicensed code. Game-specific facts
and independent behavioral/ISA tests are distinct from a function transcription.
Retain applicable source notices and update `audit/PROVENANCE.json` only after
review. Do not copy a third-party implementation without its licence/attribution.

Bug reports should identify converter/profile version, settings, concise error
codes and reproduction steps. Redact personal paths, contact information and
credentials from any diagnostic excerpt. Do not upload a complete generated
folder, raw dump, save, screenshot containing game data or unreviewed log archive.

Read AGENTS.md and docs/RELEASE_AUDIT.md before an authorized source export or
publication. Routine local work does not grant permission to push or deploy.
